# Component Lab — React and TypeScript

A responsive admin interface using reusable components, status badges, sortable and filterable rows, a modal, and empty/loading/error states. Data is local illustrative demo content.

## Run

```bash
npm install
npm run dev
```

**Build verification:** `npm run build` (Node.js 20+). No backend is needed. The UI was generated for portfolio demonstration and should be tested in your own browser before sharing.
